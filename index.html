API Documentation

POST /api/chat Chat Completion

Accepts a conversation array and streams or returns an AI assistant response.

curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemini-2.5-flash",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'
GET /api/health Health Check

Monitors service health, memory usage, and runtime framework status.

GET /api/download/apk Android APK Binary

Directly serves the compiled 23MB Android APK artifact (app-debug.apk) with instant browser download.
